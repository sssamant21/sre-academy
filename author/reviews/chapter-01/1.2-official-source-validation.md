## Validation Summary

No blocking factual issue was found in the Chapter 1.2 author draft.

The draft is aligned with official Kubernetes documentation on these points:

- Kubernetes objects are persistent entities used to represent cluster state.
- Object `spec` describes desired state and object `status` describes observed state.
- Kubernetes uses the API to create, update, modify, and delete objects.
- Controllers are control loops that watch cluster state and work to move current state closer to desired state.
- Controllers commonly act through the API server rather than directly running containers themselves.
- The cluster model separates control plane components from node components.
- Readiness is distinct from process existence and affects whether Pods should receive Service traffic.
- HPA is a controller-style mechanism driven by metrics and control loop behavior.
