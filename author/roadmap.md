# Authoring Roadmap

## Objective

Maintain a scalable authoring workflow for the SRE-Academy Kubernetes Engineering Handbook.

## Near-Term Focus

- Complete Chapter 7 manuscript sections.
- Track section progress in dedicated progress files.
- Validate diagrams, examples, and labs before publication.
- Keep published content separate from authoring support material.

## Chapter 7 Workflow

1. Add manuscript content to the canonical section file.
2. Update the matching progress tracker.
3. Validate Markdown, Mermaid diagrams, and links.
4. Run MkDocs build.
5. Complete engineering and editorial review.
6. Publish through a pull request.

## Future Work

- Add reusable lab templates.
- Add diagram conventions.
- Add release notes for completed handbook milestones.
