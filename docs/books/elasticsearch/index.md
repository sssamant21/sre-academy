# Elasticsearch

The Elasticsearch book will document search and analytics operations from index design through production troubleshooting.

## Planned chapters

- Cluster topology, nodes, shards, and replicas
- Index lifecycle management and data retention
- Query performance and mapping strategy
- Snapshot, restore, and disaster recovery
- Health checks, alerting, and capacity planning

## Starter reliability questions

1. Are shards balanced and sized appropriately?
2. Which indexes drive the most important user journeys?
3. How do we restore service after data or node loss?
