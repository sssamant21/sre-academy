# GitHub Actions

The GitHub Actions handbook will document CI/CD workflow design, reliability, and operations.

## Planned chapters

- Workflow triggers, jobs, runners, and permissions
- Build, test, release, and deployment pipelines
- Secrets, environments, approvals, and policy gates
- Caching, artifacts, concurrency, and performance
- Troubleshooting failed or stuck workflow runs

## Starter reliability questions

1. Which workflows block production delivery?
2. What permissions does each workflow actually need?
3. How do we recover from runner, cache, or dependency failures?
