# Amazon MSK

Amazon MSK guidance lives under Apache Kafka for Kafka operations and inside the AWS handbook for AWS platform operations.

## Kafka-focused scope

- Cluster sizing, broker storage, and networking
- Topic, partition, and replication strategy
- Client connectivity, authentication, and authorization
- Monitoring, scaling, patching, and recovery
- Migration and disaster recovery runbooks

## Cross-reference

Use the AWS handbook for IAM, VPC, CloudWatch, account architecture, and other AWS services that support MSK.
