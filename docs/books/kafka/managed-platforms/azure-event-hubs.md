# Azure Event Hubs for Kafka

Azure Event Hubs can accept Kafka protocol clients while remaining an Azure-native event streaming service.

## Kafka-focused scope

- Kafka protocol compatibility boundaries
- Namespace, event hub, partition, and throughput planning
- Authentication, networking, and private endpoint patterns
- Consumer behavior, offsets, lag, and replay expectations
- Monitoring, alerting, and recovery runbooks
