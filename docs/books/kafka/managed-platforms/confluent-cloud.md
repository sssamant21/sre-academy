# Confluent Cloud

Confluent Cloud guidance lives under Apache Kafka because it is a managed Kafka platform with SaaS-specific operational boundaries.

## Kafka-focused scope

- Cluster type, capacity, networking, and region choices
- Topic, partition, retention, and schema governance
- Client authentication, authorization, and private connectivity
- Monitoring, quotas, billing signals, and incident response
- Migration, disaster recovery, and provider support workflows

## Cross-reference

Use cloud provider handbooks for private networking, identity, and regional dependencies that support Confluent Cloud integrations.
