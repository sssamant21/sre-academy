# Google Managed Service for Apache Kafka

Google Managed Service for Apache Kafka guidance lives under Apache Kafka for Kafka operations and inside the GCP handbook for Google Cloud platform operations.

## Kafka-focused scope

- Cluster provisioning, sizing, and network access
- Topic, partition, and replication planning
- Client authentication, connectivity, and workload migration
- Monitoring, scaling, and operational recovery
- Disaster recovery and provider dependency review

## Cross-reference

Use the GCP handbook for projects, IAM, VPC networking, Cloud Monitoring, and provider-level operational guidance.
