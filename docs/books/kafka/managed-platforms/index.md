# Managed Kafka Platforms

Managed Kafka platforms are documented under Apache Kafka so provider-specific operations stay connected to Kafka fundamentals.

## Platforms

- Amazon MSK
- Azure Event Hubs for Kafka protocol
- Google Managed Service for Apache Kafka
- Confluent Cloud

## Scope

Use this section for platform-specific provisioning, networking, authentication, monitoring, scaling, upgrade, and recovery guidance. Keep Kafka concepts such as topics, partitions, consumers, producers, retention, and lag in the main Apache Kafka handbook.
