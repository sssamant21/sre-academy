# GitOps

GitOps is documented inside the Enterprise Kubernetes handbook as the operating model for declarative Kubernetes delivery and drift management.

## Scope

- Desired state in Git
- Reconciliation, drift detection, and promotion workflows
- Environment boundaries and approval gates
- Operational ownership between platform and application teams
- Integration points with Argo CD and Flux-style controllers

## Operational guidance

Use this section for Kubernetes GitOps patterns. Use the standalone Argo CD handbook for detailed Argo CD operations, access control, sync behavior, and troubleshooting.
