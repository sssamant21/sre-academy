# Helm

Helm is documented inside the Enterprise Kubernetes handbook because it is primarily an application packaging and release workflow for Kubernetes platforms.

## Scope

- Chart structure, values, and templating basics
- Release lifecycle, upgrades, rollbacks, and history
- Dependency management and chart repositories
- Secrets, environment configuration, and promotion safety
- Testing, linting, and operational runbooks

## Operational guidance

Use Helm guidance to standardize how platform and application teams package Kubernetes workloads, review release changes, and recover from failed upgrades.
