# Kustomize

Kustomize is documented inside the Enterprise Kubernetes handbook because it manages Kubernetes-native configuration overlays and environment-specific customization.

## Scope

- Bases, overlays, patches, and generators
- Environment promotion and configuration review
- Image updates, labels, annotations, and common transforms
- Validation, diffing, and deployment safety
- Troubleshooting broken overlays

## Operational guidance

Use Kustomize guidance to keep rendered manifests predictable across environments while avoiding duplicated Kubernetes configuration.
