# Amazon EKS

Amazon EKS guidance lives under Enterprise Kubernetes for Kubernetes operations and inside the AWS handbook for AWS platform operations.

## Kubernetes-focused scope

- Cluster version and upgrade planning
- Node groups, add-ons, and workload scheduling
- IAM Roles for Service Accounts and pod identity patterns
- VPC CNI behavior and cluster networking
- Control plane logs, metrics, and incident response

## Cross-reference

Use the AWS handbook for AWS account, IAM, VPC, EC2, CloudWatch, Route 53, and other provider services that support EKS.
