# Azure AKS

Azure AKS guidance lives under Enterprise Kubernetes for Kubernetes operations and inside the Azure handbook for Azure platform operations.

## Kubernetes-focused scope

- Cluster version and upgrade planning
- Node pools, add-ons, and workload scheduling
- Azure identity integration for workloads
- CNI, private clusters, and ingress patterns
- Control plane diagnostics, metrics, and incident response

## Cross-reference

Use the Azure handbook for subscriptions, identity, Virtual Network, Key Vault, Azure Monitor, and other provider services that support AKS.
