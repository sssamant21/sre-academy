# Google GKE

Google GKE guidance lives under Enterprise Kubernetes for Kubernetes operations and inside the GCP handbook for Google Cloud platform operations.

## Kubernetes-focused scope

- Cluster release channels and upgrade planning
- Node pools, autopilot tradeoffs, and workload scheduling
- Workload Identity and access patterns
- VPC-native clusters, ingress, and service networking
- Cloud Logging, Cloud Monitoring, and incident response

## Cross-reference

Use the GCP handbook for projects, IAM, networking, Cloud Monitoring, Cloud SQL, Cloud Storage, Pub/Sub, and other provider services that support GKE.
