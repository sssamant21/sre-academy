# MongoDB Production Engineering Series — Master TOC v1.0

**Status:** LOCKED

## Book 1 — MongoDB Administration Handbook

Primary audience: MongoDB DBAs and administrators.

Core scope: architecture fundamentals, installation/configuration/upgrades, databases and collections, BSON, WiredTiger, schema/data modeling, indexes, security, replica sets, backup/recovery, monitoring, maintenance, troubleshooting, and DBA runbooks.

## Book 2 — MongoDB SRE & Reliability Engineering Handbook

Primary audience: SRE and platform engineers.

Core scope: reliability architecture, SLI/SLO/SLA, observability, monitoring and alerting, capacity engineering, replication reliability, incident response, failure recovery, automation, chaos/DR testing, and production case studies.

## Book 3 — MongoDB DBRE & Performance Engineering Handbook

Primary audience: DBREs and senior MongoDB engineers.

Core scope: MongoDB/WiredTiger internals, query execution, query planner, explain plans, indexing internals, storage engineering, working-set analysis, performance engineering, sharding, shard-key engineering, resharding, benchmarking, and large-scale production workloads.

## Book 4 — MongoDB Cloud & Kubernetes Production Handbook

Primary audience: SRE, DBRE, cloud, Kubernetes, and platform engineers.

Core scope: MongoDB Atlas, AWS, Azure, Google Cloud, Kubernetes deployments, persistent storage, backup/restore, scaling, upgrades, DR, Terraform, Ansible, Helm, GitOps/Argo CD, secrets, CI/CD, and reference architectures.
