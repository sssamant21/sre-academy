# MongoDB Production Engineering Series

**Architecture Version:** 1.0  
**Status:** Locked

This series provides production-grade MongoDB guidance for DBA, DBRE, SRE, cloud, and platform engineering roles.

## Locked Books

1. **MongoDB Administration Handbook** — DBA administration, configuration, security, backup, replication, upgrades, and routine operations.
2. **MongoDB SRE & Reliability Engineering Handbook** — reliability, observability, capacity, incidents, recovery, automation, and SRE practices.
3. **MongoDB DBRE & Performance Engineering Handbook** — internals, query/index/storage engineering, scaling, sharding, and performance.
4. **MongoDB Cloud & Kubernetes Production Handbook** — MongoDB Atlas, AWS, Azure, Google Cloud, Kubernetes, GitOps, IaC, and production reference architectures.

## Standard Workflow

Planned → Draft → Technical + Source Review → Production + Copyright Review → Revised Final / Canonical Edition

## Technical Validation

Technical claims must be validated against current official MongoDB documentation. Content must clearly distinguish MongoDB Community, Enterprise Advanced, Atlas, Kubernetes, and version-specific capabilities where applicable.

## Standard Operational Pattern

Major operational topics should follow:

Architecture → Configuration → Best Practices → Monitoring → Alerting → Failure Scenarios → Troubleshooting → Recovery → Automation → Production Case Studies

The four-book architecture is locked and should not be changed without an explicit architecture revision.
