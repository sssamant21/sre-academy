# Multi-Cloud

The Multi-Cloud handbook will document patterns for operating systems across more than one cloud provider.

## Planned chapters

- Account and project strategy across providers
- Identity, networking, observability, and governance
- Portability, service dependencies, and platform boundaries
- Cost, resilience, and disaster recovery tradeoffs
- Operational runbooks for cross-cloud incidents

## Starter reliability questions

1. Which workloads truly need multi-cloud support?
2. Where are provider-specific dependencies hidden?
3. How do we test cross-cloud recovery without adding unnecessary complexity?
