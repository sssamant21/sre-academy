# Gateway API

Gateway API guidance covers modern Kubernetes traffic routing resources and operational patterns.

## Scope

- GatewayClass, Gateway, HTTPRoute, and policy resources
- Listener, route, and backend ownership models
- Cross-namespace routing and delegation
- Migration from Ingress where appropriate
- Operational runbooks for gateway routing failures

## Cross-reference

Use the Enterprise Kubernetes handbook for cluster operations and the Networking handbook for traffic management fundamentals.
