# Networking

The Networking handbook covers the network foundations behind reliable services. NGINX and other proxies are documented here as implementation topics rather than standalone flagship handbooks.

## Topics

- DNS
- TCP/IP
- HTTP/HTTPS
- Reverse Proxy
- Load Balancing
- TLS
- Service Discovery
- NGINX
- Envoy
- HAProxy
- Traefik
- Kubernetes Ingress
- Gateway API

## Reliability focus

Use this handbook for traffic routing, name resolution, secure transport, proxy behavior, ingress patterns, service discovery, and network troubleshooting.
