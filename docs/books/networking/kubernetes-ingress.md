# Kubernetes Ingress

Kubernetes Ingress guidance covers HTTP routing into Kubernetes workloads and the operational boundary between networking and Kubernetes platforms.

## Scope

- Ingress resources, controllers, classes, and annotations
- Host and path routing patterns
- TLS termination and certificate automation
- Controller health, backend readiness, and traffic debugging
- Operational runbooks for ingress outages

## Cross-reference

Use the Enterprise Kubernetes handbook for cluster-level Kubernetes operations and the Networking handbook for proxy, TLS, and load balancing fundamentals.
