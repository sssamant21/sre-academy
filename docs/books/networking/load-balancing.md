# Load Balancing

Load balancing is documented inside the Networking handbook because traffic distribution is a core networking reliability pattern.

## Scope

- Layer 4 and Layer 7 load balancing patterns
- Health checks, routing, and failover behavior
- Connection draining, retries, and timeouts
- Capacity, scaling, and regional resilience
- Troubleshooting traffic imbalance and failed backends
