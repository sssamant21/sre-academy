## Scope

- Server blocks, upstreams, routing, and TLS
- Reverse proxy, caching, and static asset patterns
- Timeouts, retries, buffers, and rate limits
- Logging, metrics, reloads, and configuration validation
- Troubleshooting failed upstreams and traffic errors
