# 6.17 -- JIT Compilation and CPU-Intensive Query Execution

**Status:** Complete -- Revised Final / Canonical Edition

PostgreSQL can use just-in-time compilation for eligible expensive execution work. JIT has compilation overhead and is most useful when execution savings exceed that startup cost; short OLTP queries may not benefit.

Inspect JIT plan details and workload-level JIT statistics where available. Diagnose CPU-intensive queries first for row volume, expression cost, joins, aggregation, estimates, and access paths. Do not enable/disable JIT globally based on a single query. Benchmark representative latency distributions and CPU consumption before changing thresholds or policy.
