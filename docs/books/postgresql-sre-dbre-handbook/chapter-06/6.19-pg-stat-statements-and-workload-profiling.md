# 6.19 -- pg_stat_statements and Query Workload Profiling

**Status:** Complete -- Revised Final / Canonical Edition

`pg_stat_statements` tracks planning/execution statistics for normalized statements when configured and enabled. It supports workload prioritization by total execution time, calls, mean/min/max/stddev execution time, rows, buffer activity, temporary blocks, WAL, JIT, and parallel-worker fields available in the installed PostgreSQL version.

Example prioritization:
```sql
SELECT queryid, calls, total_exec_time, mean_exec_time, rows,
       shared_blks_read, temp_blks_written
FROM pg_stat_statements
ORDER BY total_exec_time DESC
LIMIT 20;
```

Total database impact and tail latency matter more than ranking only by average duration. Treat query text as potentially sensitive, control access, understand reset windows/evictions, and preserve baselines before resets or upgrades.
