# 6.23 -- Query Performance Monitoring, Metrics, and Alerting

**Status:** Complete -- Revised Final / Canonical Edition

Monitor query latency distributions, total database time by query, calls, active/waiting sessions, lock waits, buffer reads/hits, temporary I/O, WAL generation, CPU, IOPS/latency, connection pressure, parallel-worker utilization, and plan changes for critical queries.

Alert on sustained user impact and abnormal deviation from baselines rather than arbitrary universal query-duration thresholds. A five-second analytical query may be normal while a 200-ms OLTP query can violate an SLO.

Alerts should identify service/database, query identity where safe, duration, baseline deviation, waits/resources, and a runbook. Control SQL-text exposure because telemetry may contain sensitive information.
