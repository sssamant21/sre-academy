# 6.5 -- Cardinality, Selectivity, and Row-Count Estimation

**Status:** Complete -- Revised Final / Canonical Edition

Cardinality estimation predicts rows flowing through plan nodes; selectivity estimates predicate filtering. These estimates influence scan type, join order/method, aggregation, parallelism, and memory behavior.

Compare `rows=` estimates with `actual rows=` from safely obtained execution plans. Large errors can originate in stale statistics, skew, correlated columns, expressions, rapidly changing tables, unusual parameter values, or compound predicates.

Remediation sequence: confirm data distribution -> refresh appropriate statistics -> evaluate statistics targets -> evaluate extended statistics for correlated columns -> review indexes/query formulation -> retest with representative parameters. Do not treat a single misestimate as justification for globally inflating statistics targets.
