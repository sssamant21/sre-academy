# 6.6 -- Planner Statistics and ANALYZE

**Status:** Complete -- Revised Final / Canonical Edition

`ANALYZE` collects statistics the planner uses to estimate row counts and distributions. Autovacuum can perform automatic analyze based on table-change thresholds. Statistics are sampled estimates, not exact table inventories.

Monitor `last_analyze`, `last_autoanalyze`, modification activity, plan-estimation accuracy, and tables with rapid or highly skewed change. After bulk loads, large distribution changes, or major data migrations, consider an explicit ANALYZE when operationally appropriate.

Higher statistics targets can improve estimates for selected columns but increase collection and planning overhead/storage. Apply them selectively and validate the result. Never disable autoanalyze as a generic performance fix.
