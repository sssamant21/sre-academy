# 6.7 -- Extended Statistics and Correlated Columns

**Status:** Complete -- Revised Final / Canonical Edition

Single-column statistics cannot fully model relationships among correlated predicates. PostgreSQL extended statistics can capture multivariate information such as dependencies, multivariate distinct counts, and most-common-value combinations for selected column groups.

Typical workflow:
```sql
CREATE STATISTICS orders_region_status_stats
    (dependencies, mcv)
ON region, status
FROM orders;
ANALYZE orders;
```

Create statistics objects only for demonstrated estimation problems; PostgreSQL does not automatically create every possible multicolumn combination. Validate estimated-vs-actual rows before and after the change and include ANALYZE behavior in deployment procedures.
