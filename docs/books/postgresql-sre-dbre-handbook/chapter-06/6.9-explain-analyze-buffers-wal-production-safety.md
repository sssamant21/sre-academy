# 6.9 -- EXPLAIN ANALYZE, BUFFERS, WAL, and Production-Safe Plan Analysis

**Status:** Complete -- Revised Final / Canonical Edition

`EXPLAIN ANALYZE` executes the statement. That makes it powerful and potentially dangerous, especially for DML or expensive queries. Use production-safe controls and understand side effects before running it.

For safe read-only investigations where appropriate:
```sql
EXPLAIN (ANALYZE, BUFFERS, VERBOSE, SETTINGS)
SELECT ...;
```

Review actual time/rows/loops, rows removed by filters, shared/local/temp buffer activity, sort/hash spill, worker behavior, and estimate error. WAL reporting can be useful for write analysis when supported/appropriate.

Never run an unbounded expensive `EXPLAIN ANALYZE` in production merely to see why a query is slow. Prefer lower-risk evidence, replicas/test environments, statement limits, and representative replay when possible.
