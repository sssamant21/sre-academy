# 7.15 — Operator Classes, Operator Families, and Collations

**Status:** Complete — Revised Final / Canonical Edition

## Purpose

Explain why index usability depends on operator semantics, data types, and collation behavior.

## Canonical Guidance

Operator classes tell an index access method which operators and ordering semantics apply to a data type. Operator families relate compatible classes. Collations can affect comparison and ordering behavior, especially for text.

```sql
CREATE INDEX idx_customer_name_pattern
ON customers (name text_pattern_ops);
```

## Production Review

Use explicit operator classes only when the query operators and locale/collation semantics require them. Test upgrades that change collation providers or versions because changed ordering rules can have index correctness implications and may require reindexing according to platform guidance.

## Production Rules

1. Index compatibility is operator-specific.
2. Text indexing must account for collation semantics.
3. Treat collation changes as production index events, not cosmetic configuration changes.
