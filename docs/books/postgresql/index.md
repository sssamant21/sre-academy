# PostgreSQL

The PostgreSQL book will document reliable relational database operations for production systems.

## Planned chapters

- Architecture, connections, roles, and database lifecycle
- Schema changes, migrations, and release safety
- Backup, restore, replication, and point-in-time recovery
- Query performance, indexing, vacuum, and maintenance
- Monitoring, alerting, failover, and operational runbooks

## Starter reliability questions

1. How do we prove backups can be restored?
2. Which schema changes require extra rollout safeguards?
3. What signals show replication lag, lock contention, or query degradation?
