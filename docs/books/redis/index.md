# Redis

The Redis book will cover reliable use of Redis as a cache, queue, session store, and fast data structure service.

## Planned chapters

- Data structures and workload patterns
- Cache design, expiration, and invalidation
- Persistence, replication, and high availability
- Memory sizing, eviction, and performance tuning
- Failover testing, monitoring, and operational runbooks

## Starter reliability questions

1. What happens when Redis is unavailable?
2. Which keys and workloads are most memory sensitive?
3. How do clients behave during failover?
