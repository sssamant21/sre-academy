# Snowflake Enterprise Handbook Assessments

Version: v1.2.0  
Status: In development  
Last reviewed: 2026-08-15

The assessment program covers all 20 chapters with 60 questions: one concept question, one operational question and one scenario question per chapter.

## Assessment sets

- [Chapters 1–5](chapters-01-05.md)
- [Chapters 6–10](chapters-06-10.md)
- [Chapters 11–15](chapters-11-15.md)
- [Chapters 16–20](chapters-16-20.md)

Complete each set before consulting the [answer appendix](answers/index.md).

## Scoring

Each question is worth two points:

- 2: correct answer with chapter-supported reasoning;
- 1: partially correct or missing an important constraint;
- 0: incorrect, unsafe or unsupported.

Each five-chapter set is worth 30 points. Suggested interpretation:

- 27–30: advanced mastery
- 23–26: operationally ready
- 18–22: review weak chapters
- below 18: repeat the set after study

Scenario answers are evaluated for evidence, safety, reversibility and validation—not wording.
