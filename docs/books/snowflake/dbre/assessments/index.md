## Scoring

Each question is worth two points:

- 2: correct, safe and supported reasoning;
- 1: partially correct but missing an important constraint;
- 0: incorrect, unsafe or unsupported.

Maximum score: 60.

| Score | Interpretation |
|---:|---|
| 54–60 | Advanced DBRE mastery |
| 46–53 | Operationally ready |
| 36–45 | Targeted remediation required |
| Below 36 | Repeat labs and assessment |

Scenario answers are evaluated for evidence, safety, authorization, reversibility and validation—not exact wording.
