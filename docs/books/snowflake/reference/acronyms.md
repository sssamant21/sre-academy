# Snowflake Acronym Reference

Version: v1.2.0  
Status: Production Release  
Last vendor validation: 2026-08-15

| Acronym | Meaning | Handbook context |
|---|---|---|
| ABAC | Attribute-Based Access Control | Policy decisions using identity or object attributes |
| API | Application Programming Interface | Programmatic access and integrations |
| BI | Business Intelligence | Reporting and analytical consumption |
| CI | Continuous Integration | Automated validation of changes |
| CD | Continuous Delivery/Deployment | Controlled promotion to environments |
| COA | Course of Action | Operational remediation plan |
| DAG | Directed Acyclic Graph | Task-graph dependency structure |
| DDL | Data Definition Language | Create, alter and drop objects |
| DML | Data Manipulation Language | Insert, update, delete and merge data |
| DR | Disaster Recovery | Replication, failover and recovery |
| ETL | Extract, Transform, Load | Data integration pattern |
| ELT | Extract, Load, Transform | Snowflake-centered transformation pattern |
| FGAC | Fine-Grained Access Control | Row, column, masking and related policies |
| IaC | Infrastructure as Code | Declarative platform configuration |
| IdP | Identity Provider | SSO and federated identity system |
| KPI | Key Performance Indicator | Executive or service outcome |
| MFA | Multi-Factor Authentication | Authentication with multiple factors |
| MTTR | Mean Time to Restore/Resolve | Incident recovery measure |
| OAuth | Open Authorization | Token-based delegated authorization |
| PII | Personally Identifiable Information | Sensitive-data classification |
| PHI | Protected Health Information | Regulated healthcare data |
| RBAC | Role-Based Access Control | Privileges assigned through roles |
| RCA | Root Cause Analysis | Post-incident causal analysis |
| RPO | Recovery Point Objective | Acceptable data-loss window |
| RTO | Recovery Time Objective | Acceptable restoration duration |
| SaaS | Software as a Service | Snowflake delivery model |
| SCIM | System for Cross-domain Identity Management | Identity provisioning |
| SLI | Service-Level Indicator | Measured reliability or performance signal |
| SLO | Service-Level Objective | Target for an SLI |
| SLA | Service-Level Agreement | Contractual service commitment |
| SQL | Structured Query Language | Query and administrative language |
| SRE | Site Reliability Engineering | Reliability-focused operations |
| SSO | Single Sign-On | Federated authentication experience |
| TLS | Transport Layer Security | Encrypted client communication |
| UDF | User-Defined Function | Reusable custom function |
| UTC | Coordinated Universal Time | Required incident timeline standard |
| VPC/VNet | Virtual Private Cloud/Network | Cloud networking boundary |
| VPCE | VPC Endpoint | Private connectivity identifier |
| YAML | YAML Ain't Markup Language | CI/CD and configuration files |
