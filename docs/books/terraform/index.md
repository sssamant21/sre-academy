# Terraform

The Terraform handbook will document infrastructure as code practices for reliable platform changes.

## Planned chapters

- State, providers, modules, and workspaces
- Plan review, policy checks, and change safety
- Environment promotion and reusable module design
- Remote state, locking, drift, and recovery
- Operational runbooks for failed applies

## Starter reliability questions

1. Who owns each state file?
2. How do we review blast radius before apply?
3. What is the recovery path for a partial infrastructure change?
