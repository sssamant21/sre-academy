# SRE Academy

Welcome to the SRE Academy documentation site.

## What belongs here

Use this site to collect course notes, runbooks, reliability engineering practices, and hands-on exercises.

## Local preview

Install the documentation dependencies and start the development server:

```bash
pip install -r requirements.txt
mkdocs serve
```

Then open the local URL printed by MkDocs.

## Publishing

Changes merged to `main` are built by GitHub Actions and deployed to GitHub Pages.
